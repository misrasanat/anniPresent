# Assets Folder - OurFlix Edition

Add your images and videos here with these exact names:

## Main Video
- `main-video.mp4` - The hero video that plays at the top and in the special card

## Memory Lane Photos (for the scrolling galleries)
- `memory1.jpg` through `memory8.jpg` - Photos for the Memory Lane section

## Poem Slideshow Photos
- `poem1.jpg` through `poem10.jpg` - Photos that display with each poem verse

You can use `.jpg`, `.jpeg`, or `.png` formats for images.
Make sure the filenames match exactly!

## Quick Setup Guide

1. Add `main-video.mp4` - your big anniversary montage
2. Add 8 photos for Memory Lane (memory1.jpg - memory8.jpg)
3. Add 10 photos for the poem slideshow (poem1.jpg - poem10.jpg)
4. Customize the poems in app.js (POEM_SLIDES array)
5. Customize profile names in app.js (PROFILES array)

That's it! Open index.html in your browser.
